# Automatic native partial export

Retained per-case full packets are authoritative for export, including failed batch summaries and cancelled outer done wrappers with no progress field. The exporter still requires the exact source/root/model/native proof. Unsupported or unverified interrupted packets remain raw and retain their export rejection. Queued cases without packets cannot be admitted.

A failed goal can produce `natlang.training-scope/2` only through a registered complete independent return contract. Initial GAD contracts bind the actual native history or roster, corresponding native check, entire expected judgment, source/instructions, exact captured argument/return hashes and an effect-free subtree. They do not accept arbitrary successful calls, typeshape alone, or a namespace claim. The full original failed packet and failed outcome remain immutable inputs; completion stays false. Existing successful whole-goal export is unchanged.

Opt out with `VIBESTUDIO_NATIVE_PARTIAL_SALVAGE=0` or `--no-partial-salvage`. Reader deployment must precede registering this new cohort: legacy reader2a877 rejects scope/2. The minimum supported reader is the commit containing Verify source-bound native return certificates for partial live trajectories (branch fix/independent-partial-admission). Neither this change nor its tests register training data.

Validation: 135 collector/exporter/native-contract controls; actual archived failed GAD raw gives all three captured calls, exactly one correct interpretQuestion decision, no wrong-roster decision, and task_completed=false through Python NativeIR and Node materialization. Reader checks include source/native/value/capture forgery, effects and scope downgrade. No provider/model calls.
