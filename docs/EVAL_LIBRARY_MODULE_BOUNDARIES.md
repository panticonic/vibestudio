# Shared eval libraries and per-run imports

EvalDO.loadLibraryModule executes shared providers with STATELESS_ISOLATE_MODULES only (node:async_hooks and node:util/types). The Natlang provider imports service declarations through the public services barrel. A Node-only comparison import in an unrelated barrel export therefore broke provider initialization before any teacher invocation. Base97c8427 removes that dependency using an exact comparator for the native strict JSON handle/checkpoint/snapshot schemas.

Ordinary workspace imports take a different route: EvalDO builds the runModuleMap from createEvalNodeCompat, the context-bound hosted runtime, and the loaded Natlang provider, then gives that map and makeLoadImport to engine.executeSandbox. Its existing bounded util/crypto/buffer/path facades are intentional. SST managed domains can use those interfaces; moving all their comparisons to a JSON-only comparator would change unsupported domains without justification. No broad migration was shipped.

The regression uses real selected workspace bundles and EvalDO's actual shared loader, followed by the real eval engine importing SST CLI and the owned-operations managed domain with run-local compatibility modules. Host retention transport and native operation transport are test-only seams: exact artifact references are asserted; unused native operations refuse. No model/provider operations run. node:util remains absent from the shared loader after ordinary imports. This is a load-boundary control, not a claim that native operations or whole open goals were executed.

The loader's private global requires disabled dynamic code generation. tests/fixtures/evalLibraryBoundary.case.ts runs in a dedicated child Vitest process, which owns irreversible realm taming. src/server/buildV2/evalLibraryBoundary.test.ts joins that child so unrelated Host test files retain their own compiler environment. tests/evalLibraryBoundary.config.ts selects only that fixture; the normal Host test glob cannot also run it directly.

Checked: actual provider/engine/hosted-runtime CJS initialization, actual SST CLI/domain import, shared-module denial, canonical retention descriptor and artifact identity; Base35 comparator/oracle/native-operation controls.
