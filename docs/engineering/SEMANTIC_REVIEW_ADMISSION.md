# Independent source-claim review admission

Application functions return native domain values. Source claims are assessed by
an independent typed Natlang assessor after exact source bytes, quote spans,
task identity and actual returned values are bound. It never supplies teacher
targets or a task execution route.

## Mechanism inventory and decomposition

- Case catalog: research, research-and-edit, owned variants and assigned public
  briefs require the configured independent reviewer before teacher execution.
- Outcome evidence: bind review goal/JSON answer to the original application
  result and citations; retain captured source hashes and assigned-source scope.
  These are exact verifiers, hence crisp.
- Semantic policy: scripts/reviews/assessPublicClaims.nl assesses source claims;
  independent workspace-effect checks continue to decide requested edits.
- Export: reuse retained reviews only for identical input, model, teacher and
  assessor source/type bytes, provider exchange identity and consistent verdict.
  Keep stale reviews beside their replacements.
- Training: manifests bind review evidence; reviewer exchanges never enter the
  teacher graph or supervised targets. Existing content review remains intact.
