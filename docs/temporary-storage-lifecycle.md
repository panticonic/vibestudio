## Native templates and instance state

Base `extensions/test-runner/index.ts` creates `vibestudio-native-tests-*`; shell `snugServer.ts` creates `snug-*`; Git bridge creates export scratch. Guest code cannot reap itself after SIGKILL. The shared host native execution policy previously set TMPDIR/TMP/TEMP to persistent `home/tmp`, allowing those directories to outlive runtime incarnation retirement. The coordinated native-runtime successor owns that policy repair and all its consumers. SST/Google/Spectrolite `runtime.fs.mkdtemp` calls are workspace-relative `.tmp` resources, not Node host `/tmp` creators. No frozen template is changed for this inventory.

Managed disposable instance generations previously retained entire state roots. The coordinated instance-lifecycle successor retires actual runtime state after process retirement and retains only explicit capture evidence. Genuine explicit persistent developer instances remain persistent. Historical directory deletion belongs to the operator's separate inactive-owner/hardlink inventory; this code does not infer safe deletion from age or name.

## Validation

Focused checks cover normal release, explicit retention, failed partial copy, actual owner SIGKILL with a compiler subprocess, exact browser database/WAL ownership, SQLite-close failure, and existing reader/entry behavior. Source tests must run under the memory ledger before reporting a pass; a queued or OOM-killed check is not a pass. No paid model inference, campaign or frozen-source build is part of this repair.


Actual validation (2026-11-25):

Lint uses repository rules with type-aware compilation explicitly disabled and the normal separate scripts config; existing warnings remain warnings. This is not a full semantic typecheck.

An initial dependency setup failed before most tests because this isolated worktree lacked compiled infrastructure exports. Private package links were corrected; existing compiled artifacts were reused only after exact package-source Git tree equality. The initial scoped lint accidentally inherited full type-aware compilation and was OOM-killed at its diagnostic 0.5 GiB cap; it did not pass. That unintended full compile was replaced with the bounded, explicit syntax-lint check above. No memory ceiling was raised to hide that failure.
