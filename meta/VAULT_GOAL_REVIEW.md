# Vault goal review admission

Vault tasks now separate native effects from the answer actually requested by a query. A reference route, internal review array, diagnostic editor identity or report enum is not a user outcome.

The Spectrolite fixture owns actual source observations and chronological actor operations. It keeps authority/source-before-write, current-head/CAS, protected scope, persistence and actual readback checks. Its independently bound semantic review judges the original goal against those native facts, including any explicitly requested navigation, operation order, final open document, rendering, handoff and literal answer requirements.

Consumers:

- `export-live-workflow-teacher.mjs` registers every vaultWork task for meaning review, then uses its existing captured-root input/output binding before admission. Queries bind the review answer to `proof.actualResult.answer`, already checked against original root bytes; mutations bind retained source and operation evidence.
- `lib/source-claim-admission.mjs` rejects substituted goals, answers, native observations, chronology, final state and handoff. It passes no hidden reference answer or reference route to the judge.
- `collect-live-workflow-teacher.mjs` already reads requiresReview and demands a distinct configured reviewer. No alternate collector or review route is introduced.
- `review-live-workflow-teacher.mjs` uses the existing generic actual/expected/rubric judge and captures its original request/reply. Its public-claims specialization is unchanged.
- Natlang `scripts/neuralese_data/live_teacher_sources.py:408` checks the original required review and `:449` also checks proof-declared semanticReviewRequired. Its accepted-review validation is generic over nonempty input objects; the NativeIR schema and minimum reader remain unchanged.

Old registered trajectories and their immutable proofs are untouched. The new review requirement applies to newly collected source-bound tasks. This change does not turn a nonempty answer into success: its independently captured semantic review remains mandatory.
