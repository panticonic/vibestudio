# Node-owned module/file locators

A real JSDOM qualifier test failed before test execution because Vite rewrote ownership.mjs's global new URL("./reaper.mjs",import.meta.url) as a browser asset URL. fileURLToPath then received HTTP provenance and could not locate the existing plain Node reaper. Node-only module locators now use the explicitly imported node:url URL constructor, so browser-aware transforms do not interpret them as browser assets and ambient DOM URL replacement cannot change their identity. Ownership.open({reaperPath}) remains the explicit locator override. No process/cancellation/cleanup policy changes.

Before edits, a full tracked TS/TSX/MTS/CTS/JS/MJS/CJS import.meta.url AST inventory found114 such constructors across76 files. Every selected module imports Node filesystem/path/process utilities and uses these locators for Node file reads, native helper imports/spawns, packaging, or Node test fixtures. Includes ownership/reaper asset staging, E2E owned preparation/server helpers, raw collector/export/review/package/CLI scripts, native process observer staging and their tests. Full paths/lines/consumers/Node imports are in NODE_OWNED_FILE_LOCATORS.json. The reaper itself and ownership spawn/retirement helpers have no additional module-relative global URL locator.

Nine additional projections incorrectly used encoded fileURL.pathname as a native filesystem path; these now use node:url fileURLToPath, preserving spaces, Unicode and Windows drive semantics. Three affect CLI self-entry guards; the others are native test/fixture paths. Network/browser URL interpretation remains untouched: packages/browser-import/src/normalize/favicon.ts:26,45 and packages/browser-import-archive/src/parser.ts:756 parse user/page URLs, not Node module files. No intended browser asset URL appeared among the selected tracked constructors; generated/vendored engine code is excluded and unedited (its universal/browser loading must remain portable).

Validation: real JSDOM Ownership.open→native reaper→scratch bytes→release/join→scratch absence passed, along with38 qualification/native-boundary component controls (vibe-qualified-dimensions-20261125e,42s/348MiB). This is not a live browser/teacher run. Subsequent full76-file AST restoration proved every body unchanged except the114 explicit constructor references and9 intentional file-path decodings; all changed raw JS/MJS files passed Node syntax (vibe-node-owned-url-preservation-20261126a,5.2s/195MiB). Existing Node URL/file decoding semantics settle the latter change; no repetitive library-mirror tests. No model/network probes, new cleanup framework, frozen Source41 edits, dependency installs or generated artifact hand-edits.
